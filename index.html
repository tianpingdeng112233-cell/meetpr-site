How it works

1

You write the plan

Build the week in the browser — sets, reps, load, RPE, tempo. Import an existing spreadsheet if that is how you already work.

2

They train and log

Your lifter opens the iOS app, sees today's session, and logs it set by set. Rest timer runs on the lock screen so the phone stays in the pocket.

3

You review and adjust

Actual loads, RPE, and video come back to you. Change next week before it starts, not after they have already trained it.

What is in it

Programming that survives contact with a real week

Percentage or RPE, straight sets or waves, top set and back-offs. Anchor load to a tested 1RM, an estimated 1RM, or the lifter's top set that day. Edit a whole block at once instead of cell by cell.

Video where the set is, not in a separate app

The lifter records a lift against the logged set. You scrub to the frame that matters, mark it, and draw on it. The note lands on that rep, not in a message thread three days later.

One thread per lifter

Text, images, and voice notes with each lifter, in the same place as their training. Questions about Tuesday's squats stay attached to Tuesday's squats.

A roster you can actually read

Who trained, who did not, and where each lifter's squat, bench, and deadlift are trending — across everyone you coach, on one screen.
